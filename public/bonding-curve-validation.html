1. Executive Summary

HedraFi has implemented a bonding-curve mechanism designed to provide deterministic HBAR-denominated token pricing and a programmatic purchase and redemption mechanism.

The bonding curve has been deployed and exercised on Hedera Testnet. Controlled on-chain transactions were executed to validate both primary paths of the mechanism: purchasing HRT using HBAR and selling HRT back through the curve for HBAR.

A 100 HRT purchase was successfully executed, followed by a 100 HRT redemption transaction. Both transactions were confirmed on Hedera Testnet.

The tested purchase and redemption paths executed successfully, providing verifiable on-chain evidence that the implemented bonding-curve mechanism is operational.

2. Bonding Curve Design

The HedraFi bonding curve uses a linear pricing model in which the token price is determined by the current number of tokens issued through the curve.

3. Pricing Mechanism

The bonding curve calculates the price of each token position based on the number of tokens already issued through the curve.

Price(i) = BASE_PRICE + (SLOPE × (totalMinted + i))

Total Purchase Cost = Σ Price(i)

As tokens are purchased through the curve, the tracked curve position increases and subsequent purchases are priced according to the next positions on the curve.

When tokens are sold, the contract calculates the corresponding redemption value by traversing the curve in reverse.

Price(i) = BASE_PRICE + (SLOPE × (totalMinted - 1 - i))

Total Redemption = Σ Price(i)

8. Security & Validation Controls

The implementation includes validation checks intended to prevent invalid curve operations and protect the contract's state.

  • Maximum curve supply is enforced during purchases.
  • Purchases require sufficient HBAR to satisfy the calculated curve cost.
  • Redemptions cannot exceed the current curve supply.
  • Redemptions require sufficient HBAR reserves.
  • Hedera Token Service response codes are checked after token transfer operations.
  • Administrative functions are restricted to the configured administrator.
  • Token association is handled through Hedera Token Service.
